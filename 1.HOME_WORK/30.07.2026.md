## ЭПИЗОД I: СИНХРОНИЗАЦИЯ И ВОССТАНОВЛЕНИЕ СТЕНДА

Для исключения рассинхронизации после разрыва сессий в оперативной памяти (RAM) был запущен сквозной конвейер инициализации и первичной стерилизации данных с жесткого диска [1.1].

### Первичный код (Сборка исходного DataFrame):
```python
import pandas as pd

# Шаг 1: Заглатываем файл из бункера данных
df_excel = pd.read_excel("D:/Portable_Data_Suite/data/vagon_data.xlsx")

# Шаг 2: Выжигаем регистровый хаос и пробелы в тексте
df_excel["cargo"] = df_excel["cargo"].str.lower().str.strip()
df_excel["status"] = df_excel["status"].str.lower().str.strip()

# Шаг 3: Завариваем сквозные дыры NaN
df_excel["status"] = df_excel["status"].fillna("не указан")
df_excel["number"] = df_excel["number"].fillna(0)

# Шаг 4: Уничтожаем паразитную дробную точку (переплавка в целые числа)
df_excel["number"] = df_excel["number"].astype(int)

# Шаг 5: Добавляем фактические часы простоя (ввод массива)
df_excel["fact_hours"] = [14, 12, 8, 24]

# Шаг 6: Векторная математика (расчет дельты и штрафа в рублях)
df_excel["delta_h"] = df_excel["fact_hours"] - 12
df_excel["penality_rub"] = df_excel["fact_hours"] * 500

# Шаг 7: Физическая сортировка строк в RAM по убыванию убытков
df_excel = df_excel.sort_values(by="penality_rub", ascending=False)
```

## ЭПИЗОД II: РАСЧЕТ СВОДНЫХ МЕТРИК ПО ЗАКОНУ «P» И МНЕМОНИКЕ GBYAXBOX

**Бизнес-задача:** Рассчитать точное количество физических вагонов по каждой категории груза и вычислить среднее время фактического простоя на один вагон, полностью исключив перегрузку RAM обсчетом лишних столбцов [1.1].

### Конечный боевой код с авторскими комментариями:

```python
# ПО ШАГОВОМУ МЕТОДУ (ЗАКОН P - все через переменную): Схлопываем таблицу по объектам и считаем количество:
# 1. Через точку вызываем метод .groupby() и в круглых скобках шлюза указываем ось группировки (колонку)
# 2. В прилипших квадратных скобках ["number"] фиксируем нужную для подсчета, числовую колонку для вычислений.
# 3. Через следующую точку вызываем математический агрегатор .count().
vagon_count = df_excel.groupby("cargo")["number"].count()
print("---КОЛИЧЕСТВО_ВАГОНОВ---")
print(vagon_count)

print("\n")
# Аналогичным образом строим витрину для среднего значения часов:
# 1.Создаем переменную, в которую закладываем значение: явно указывая имя таблицы, следом через точку повторяем обращение к методу .groupby(), в круглых скобках отображаем ось для группы (колонку), где следом приклеиваем колонку для вычисления
# * напомню, что методу .groupby мы последовательно передаем два значения 1) ось - колонка для группы, 2) колонку со значениями для агрегации, при этом сначала идут круглые скобки, затем квадратные:
# GBYAXBOX - авторское наименование конструкции GBY - groupby, AX - axis - ось и BOX - квадратные скобки
# через точку, после создания группы и выявления колонки для агрегации, вызываем сам агрегатор
#
average_hours = df_excel.groupby("cargo")["fact_hours"].mean()
print("---СРЕДНИЕ_ЧАСЫ_ПРОСТОЯ---")
print(average_hours)
```

### 🔬 Анатомический срез и физика RAM:
1.  **Конструкция GBYAXBOX (`groupby()[]`)** сработала как идеальное сито [1.1]. При вычислении средних часов (`average_hours`) Pandas зашел в кусты групп, вырезал квадратными скобками **только столбец `fact_hours`**, а все остальные метрики (`number`, `delta_h`, `penality_rub`) мгновенно выбросил из расчетов, сэкономив такты процессора [1.1].
2.  **Закон P (Все через переменную)** зафиксировал результаты вычислений на изолированных полках-ярлыках оперативной памяти [1.1]. Исходная таблица `df_excel` не пострадала и сохранила структуру широкой матрицы [1.1].
3.  Метка **`dtype: float64`** на среднем времени простоя доказывает, что агрегатор `.mean()` выполнил точную математическую переплавку и перевел значения в класс дробных чисел для сохранения дробной части при делении [1.1].
