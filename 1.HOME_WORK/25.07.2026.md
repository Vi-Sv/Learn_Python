##  ЭПИЗОД I: ВЕКТОРНЫЕ ВЫЧИСЛЕНИЯ НАД СТОЛБЦАМИ БЕЗ ЦИКЛОВ

Мы полностью отказались от кустарного построчного перебора данных. Движок Pandas выполняет математические операции одновременно над всем вектором (колонкой) на уровне бинарного C-кода [1.1].

### Шаг 1. Пробитие схемы таблицы и ручной десант данных

*   **Код:**
    ```python
    df_excel["fact_hours"] = [14, 12, 8, 24]
    ```
*   **Анатомический разбор в лоб:**
    *   **`df_excel[...]`** — Наш базовый шлюз-приемник [1.1]. Указывая имя новой (еще не существующей) колонки `"fact_hours"`, мы даем системе приказ расширить координатную сетку таблицы по вертикали [1.1].
    *   **`=`** — Оператор фиксации в памяти [1.1].
    *   **`[14, 12, 8, 24]`** — Структура списка (`list`) [1.1]. Количество элементов внутри строго равно числу живых строк в нашей таблице (4 строки). Данные ложатся в ячейки RAM строго сверху вниз по индексам `0, 1, 2, 3` [1.1].

### Шаг 2. Векторное вычитание константы (Дельта простоя)

*   **Код:**
    ```python
    df_excel["delta_h"] = df_excel["fact_hours"] - 12
    ```
*   **Анатомический разбор в лоб:**
    *   **`df_excel["delta_h"] =`** — Применение «Правила Ювелира» [1.1]. Мы создаем пятый столбец для дельты и принудительно перезаписываем туда результат вычислений, иначе данные улетят в воздух [1.1].
    *   **`df_excel["fact_hours"]`** — Хранилище-источник, откуда система обязана забрать исходные цифры [1.1].
    *   **`- 12`** — Оператор вычитания константы [1.1]. Pandas не запускает скрытый цикл Питона [1.1]. Он за один такт процессора бьет по всему столбцу целиком, вычитая число 12 из каждой ячейки одновременно (`14-12`, `12-12`, `8-12`, `24-12`) [1.1].

### Шаг 3. Векторное перемножение столбца на тариф (Калькуляция штрафа)

*   **Код:**
    ```python
    df_excel["penality_rub"] = df_excel["fact_hours"] * 500
    ```
*   **Анатомический разбор в лоб:**
    *   **`* 500`** — Математический оператор умножения вектора на скалярное число (тариф часа простоя в рублях) [1.1]. Система мгновенно калькулирует финансовые потери для каждой строки индивидуально в обход ручным корзинам-спискам, генерируя шестую колонку `penality_rub` [1.1].

##  ЭПИЗОД II: ХИРУРГИЧЕСКАЯ СОРТИРОВКА И ПЕРЕСТАНОВКА МАТРИЦЫ

Данные рассчитаны, но лежат хаотично. Нам нужно упорядочить хаос и выстроить строки так, чтобы главные виновники убытков ПТО возглавили таблицу [1.1].

### Шаг 4. Физическая перестановка строк в RAM по убыванию

*   **Код:**
    ```python
    df_excel = df_excel.sort_values(by="penality_rub", ascending=False)
    df_excel.head()
    ```
*   **Анатомический разбор каждого слова и параметра:**
    *   **`df_excel =`** — Критически важное переприсваивание [1.1]. Без него Pandas отсортирует таблицу только на экране (визуально), а в памяти ячейки останутся лежать в старом порядке [1.1]. Мы заставляем систему зафиксировать новый порядок строк в RAM [1.1].
    *   **`.sort_values(...)`** — Встроенный высокоскоростной метод сортировки двухмерных массивов [1.1].
    *   **`by="penality_rub"`** — Обязательный параметр-указатель внутри круглых скобок [1.1]. Приказ системе: «Используй как главный критерий и ось сортировки именно колонку штрафов» [1.1].
    *   **`,`** — Запятая-разделитель параметров внутри шлюза метода [1.1].
    *   **`ascending=False`** — Жесткий логический флаг (Повышение = Ложь) [1.1]. По умолчанию Pandas сортирует от меньшего к большему [1.1]. Передавая `False`, мы даем системе прямой приказ: «Переверни логику! Сортируй строго **по убыванию** — от максимального значения к минимальному» [1.1].
