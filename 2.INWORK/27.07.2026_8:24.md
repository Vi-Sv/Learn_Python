import os
# Принудительно отключаем русские байты CP1251 от Postgres, заставляя его отвечать на английском
os.environ["PGLANGUAGE"] = "en_US.UTF-8"

import pandas as pd
from sqlalchemy import create_engine

delivery_log = [
    {"Объект": "ЖК Центральный", "Материал": "Бетон Б25", "Тоннаж": 45},
    {"Объект": "Объект Северный", "Материал": "Бетон Б25", "Тоннаж": 38},
    {"Объект": "Участок Северный", "Материал": "Бетон Б50", "Тоннаж": 50}
]
df_facts = pd.DataFrame(delivery_log)

price_dict = [
    {"Material": "Бетон Б25", "Цена": 6500},
    {"Material": "Бетон Б50", "Цена": 7200}
]
df_price = pd.DataFrame(price_dict)


df_merged = pd.merge(df_facts, df_price, left_on="Материал", right_on="Material", how="left")
df_merged["Общая_стоимость"] = df_merged["Тоннаж"] * df_merged["Цена"]


DATABASE_URL = "postgresql+psycopg2://postgres@localhost:5433/postgres"
db_engine = create_engine(DATABASE_URL)


df_merged.to_sql("commercial_report", con=db_engine, if_exists="replace", index=False)

print("ДЕСАНТ МАТРИЦЫ В ПОСТГРЕС ЗАВЕРШЕН БЕЗ ОШИБОК.")
print("ТАБЛИЦА 'commercial_report' ОФИЦИАЛЬНО СОЗДАНА НА СКЛАДЕ СУБД!")


## ЧАСТЬ 1: ПОСТРОЧНЫЙ АНАЛИЗ СБОРКИ И МАТЕМАТИКИ (PANDAS)

### Строка 1: `import os`
* **Роль в системе:** Подключение встроенного модуля операционной системы Windows.  
* **Физика процесса:** Дает скрипту доступ к системным переменным окружения компьютера для управления поведением внешних программ.

### Строка 2: `os.environ["PGLANGUAGE"] = "en_US.UTF-8"`
* **Роль в системе:** Принудительное переключение языка системных сообщений СУБД PostgreSQL на английский.  
* **Физика процесса:** Защищает Python от капкана `UnicodeDecodeError`. Если СУБД выдаст ошибку (неверный порт/база), она прилетит на английском языке (в кодировке UTF-8), и декодер Windows не зависнет на кириллических байтах CP1251.

### Строка 3: `import pandas as pd`
* **Роль в системе:** Загрузка тяжелого промышленного движка обработки табличных матриц в RAM.  
* **Физика процесса:** Выделяет область памяти под инструменты Pandas и приклеивает к ним короткий двухбуквенный ярлык `pd` для скоростного вызова команд через точку.

### Строка 4: `from sqlalchemy import create_engine`
* **Роль в системе:** Извлечение целевого инструмента создания сетевых шлюзов из библиотеки SQLAlchemy.  
* **Физика процесса:** Не загружает всю библиотеку целиком, а точечно импортирует в память только функцию-конструктор `create_engine` для экономии ресурсов процессора.

### Строка 5: `delivery_log = [...]`
* **Роль в системе:** Создание сырьевого массива фактических поставок материалов по схеме DIL (Dict in List).  
* **Физика процесса:** Процессор создает в оперативной памяти список, внутри которого лежат изолированные словари. Каждый словарь — это отдельная строка будущей таблицы с весовой.

### Строка 6: `df_facts = pd.DataFrame(delivery_log)`
* **Роль в системе:** Сборка первой двухмерной таблицы фактов по схеме DAFLIST.  
* **Физика процесса:** Инструмент `pd.DataFrame` сканирует ключи словарей, превращает их в жесткую ось столбцов (`Объект`, `Материал`, `Тоннаж`), нумерует строки индексами от `0` до `2` и записывает адрес матрицы в переменную `df_facts`.

### Строка 7: `price_dict = [...]`
* **Роль в системе:** Создание сырьевого финансового справочника цен по схеме DIL.  
* **Физика процесса:** Выделение ячеек RAM под список словарей, содержащих утвержденную стоимость одного куба/тонны бетона от коммерческого отдела.

### Строка 8: `df_price = pd.DataFrame(price_dict)`
* **Роль в системе:** Сборка второй двухмерной таблицы-справочника по схеме DAFLIST.  
* **Физика процесса:** Превращение списка словарей в независимую матрицу с осями столбцов `Material` и `Цена`, фиксируя её по физическому адресу `df_price`.

### Строка 9: `df_merged = pd.merge(df_facts, df_price, left_on="Материал", right_on="Material", how="left")`
* **Роль в системе:** Сшивка фактов со справочником (прямой аналог оператора `LEFT JOIN` в SQL или формулы ВПР в Excel).  
* **Физика процесса:** 
    1. Параметр `how="left"` приказывает процессору удерживать левую таблицу `df_facts` в абсолютной целости (все 3 строки поставок обязаны выжить).
    2. Параметры `left_on="Материал"` и `right_on="Material"` указывают имена связующих колонок-мостов в обеих таблицах.
    3. Процессор сопоставляет строки: считывает слово `"Бетон Б25"` из левой таблицы, находит его в правой таблице, забирает оттуда соответствующую цену и приваривает её новой колонкой в результирующую матрицу `df_merged`.

### Строка 10: `df_merged["Общая_стоимость"] = df_merged["Тоннаж"] * df_merged["Цена"]`
* **Роль в системе:** Векторный расчет финансовых затрат по правилу одной таблицы.  
* **Физика процесса:** Процессор выполняет математическое действие над целыми осями (столбцами) одновременно по закону выравнивания индексов. Он берет число из колонки `Тоннаж` строки `0` и умножает на число из колонки `Цена` строки `0`. Операция идет **строго внутри одной матрицы `df_merged`**, что аппаратно защищает конвейер от появления пустот `NaN`. Результат записывается в динамически созданный столбец `Общая_стоимость`.

## ЧАСТЬ 2: ПОСТРОЧНЫЙ АНАЛИЗ ЭКСПОРТА (SQLALCHEMY)

### Строка 11: `DATABASE_URL = "postgresql+psycopg2://postgres@localhost:5433/postgres"`
* **Роль в системе:** Создание строки-паспорта с точными координатами целевого склада СУБД.  
* **Физика процесса:** Текст записывается в переменную и содержит строгую инструкцию для драйвера: тип базы (`postgresql`), бинарный переходник (`psycopg2`), пользователь-администратор (`postgres`), адрес хоста (`localhost`), твой бесконфликтный портативный порт (`5433`) и имя дефолтной базы данных (`postgres`). Пароль отсутствует, так как твой батник `start_database.bat` запущен в режиме беспарольного траста.

### Строка 12: `db_engine = create_engine(DATABASE_URL)`
* **Роль в системе:** Инициализация и запуск коннектора (трубы связи) в RAM.  
* **Физика процесса:** Функция `create_engine` принимает паспорт `DATABASE_URL`, проверяет его синтаксис и создает в оперативной памяти управляющий объект `Engine`. Он держит наготове потоки связи, готовые открыться по первому требованию Pandas. База на этом этапе еще пуста — мы лишь построили и проверили трубу.

### Строка 13: `df_merged.to_sql("commercial_report", con=db_engine, if_exists="replace", index=False)`
* **Роль в системе:** Принудительный десант готовой матрицы из оперативной памяти на жесткий диск СУБД PostgreSQL.  
* **Физика процесса:** 
    1. Метод `.to_sql()` заходит в матрицу `df_merged`, считывает имена колонок и автоматически генерирует в уме SQL-запрос `CREATE TABLE commercial_report` с нужными типами данных.
    2. Параметр `if_exists="replace"` (перезаписать) приказывает системе: если таблица с таким именем уже есть в Postgres — сначала полностью уничтожить её командой `DROP TABLE`, освобождая оператора от ручной зачистки старых отчетов.
    3. Параметр `index=False` блокирует отправку в базу технического столбца с индексами строк Python (`0, 1, 2`), защищая СУБД от мусорных колонок.
    4. Движок `db_engine` открывает затвор, и данные потоком улетают в порт `5433` прямо в физические файлы твоей папки `\data\`.

### Строка 14: `print("ДЕСАНТ МАТРИЦЫ В ПОСТГРЕС ЗАВЕРШЕН БЕЗ ОШИБОК.")`
* **Роль в системе:** Сигнальный вывод телеметрии на экран.  
* **Физика процесса:** Подтверждает, что процессор успешно дошел до финальной точки скрипта, транзакция закрыта, и данные сохранены на сервере.
